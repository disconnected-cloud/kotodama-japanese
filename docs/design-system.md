# Дизайн-система Kotodama (компьютер)

Правила, по которым строятся экраны. Новый экран должен выглядеть так же, как существующие, во всех темах.

## Цвета — только из ресурсов

Цвета задаются ключами палитры в `App.ApplyPalette` (`xplat/App.axaml.cs`) и берутся в коде через `U.B("Ключ")`.
Свой цвет прямо в странице (`"#RRGGBB"`, `Color.Parse`) не пишем: он не меняется вместе с темой.

| Ключ | Назначение |
|---|---|
| `Bg`, `Sidebar` | фон окна и бокового меню |
| `Surface`, `Surface2`, `Surface3` | карточки, вложенные блоки, неактивные заливки |
| `Stroke`, `StrokeStrong` | границы карточек; заметная граница |
| `Text` | основной текст |
| `Muted` | подписи, пояснения |
| `Faint` | третьестепенный текст (подсказки, «откроется позже») |
| `Accent`, `AccentHover`, `AccentSoft` | один акцент: главная кнопка, выбранный пункт, прогресс |
| `Good`, `Gold`, `Bad` (+ `…Soft`) | верно, «почти», ошибка |
| `OnAccent` | текст на акцентной заливке |

Темы: тёмная, светлая, «Ночь» (чёрный фон), высокий контраст; акцент — сакура, мята, индиго, янтарь.
Режим «Как в Windows» выбирает светлую или тёмную по системе.

**Контраст.** `Text`, `Muted` и `Faint` на `Bg`, `Surface` и `Surface2` — не ниже 4,5:1 (WCAG AA) во всех темах.
Это проверяет тест `ContrastTests`; меняешь палитру — он должен остаться зелёным. Полупрозрачность (`Opacity < 1`)
для текста не используем: она съедает контраст. Неактивное показываем цветом `Faint` и значком.

## Текст

| Класс (`U.T(текст, "Класс")`) | Размер | Где |
|---|---|---|
| `H1` | 28, полужирный | заголовок раздела |
| `H2` | 18, полужирный | заголовок блока |
| `H3` | 15, полужирный | заголовок карточки |
| `Body` | 14, интерлиньяж 22 | основной текст |
| `Muted` | 13, цвет `Muted` | пояснения |
| `Overline` | 12, полужирный, капс | подписи групп |

Минимальный размер текста — **12**. Японский текст — ресурс `JpFont` (встроенный Noto Sans JP), книжный — `JpSerif`
(встроенный Noto Serif JP). Шрифты не зависят от системы: кандзи выглядят одинаково на любом компьютере.

## Размеры

- Отступы: шаг 4 — 4, 8, 12, 16, 24, 32. Поля страницы — 24 (на узком окне 16).
- Скругления: 10 — кнопки и чипы, 14 — карточки в списках, 22 — большие карточки-баннеры.
- Карточка: `U.Card(...)` — фон `Surface`, граница `Stroke` 1 px, скругление 14.
- Иконки бокового меню — одноцветные (`Art.MonoIcon`), цвет `Muted`; у выбранного пункта — `Accent`.
  Цветные плитки (`Art.Icon`) — только в заголовках разделов и карточках.

## Поведение

- Одна главная кнопка на экране (`"Primary"`), остальные — обычные или `"Ghost"`.
- Анимации — через `Anim`; при «Без анимаций», на слабом компьютере и при выключенных эффектах анимации Windows
  (`Anim.Lite`) их нет, включая конфетти и тряску.
- Фокус с клавиатуры виден (рамка цвета `Accent`, стиль `:focus-visible` в `App.axaml`).
- Упражнения реализуют `IFocusPage` — открываются в режиме фокуса без бокового меню.
- Пустой экран, загрузка, ошибка: заголовок `H2`, пояснение `Muted`, одна кнопка действия по центру.

## Проверка

- `dotnet test tests/Kotodama.XTests` — контраст палитр.
- CI Windows снимает 11 экранов в тёмной теме и 6 главных — в светлой, «Ночи» и высоком контрасте,
  и сравнивает с эталонами `tests/snapshots` по областям экрана (`tools/snapdiff.py`).
- `--cliptest` на минимальном размере окна: ни одна надпись не обрезана.

## Долг

В страницах осталось около 150 цветов, заданных прямо в коде (в основном декоративные градиенты баннеров
и иллюстраций). Их стоит перенести в палитру, когда экран будет меняться.
