## 2. Замеры моделей распознавания

См. [asr-benchmark.md](asr-benchmark.md). Итог: по умолчанию small, «Максимальная» — kotoba-whisper-v2.0,
ложные зачёты ≤ 2 % у всех моделей. Набор озвучен VOICEVOX — записей учеников нет.

## 3. Оптимизации (до → после)

| Что | До | После |
|---|---|---|
| Поиск по словарю | 48 мс на запрос | 20 мс, с отменой |
| Счётчик «к повторению» | пересчёт всех карточек на каждый ответ | раз на изменение и раз в минуту |
| Чтение темы из реестра | на каждый ответ | раз в минуту |
| Разделы в памяти | все 18 навсегда | последние 6 |
| Загрузка голосов | целиком в память | потоком на диск |
| Перцентиль громкости | копия и сортировка всех отсчётов | гистограмма |
| Предзагрузка озвучки | 50 синтезов сразу при запуске | в простое, по одной, с настройкой |

Не сделано: SQLite/отображение словаря в память (6.8), генератор System.Text.Json для курса (6.9), постоянный процесс звука в Linux (6.6).

## 4. Дизайн

Снимки «до» сняты локально во всех темах; «после» — артефакт `windows-snapshots` в CI (11 экранов в тёмной теме,
6 главных — в светлой, «Ночи» и высоком контрасте). Сделано: одноцветное меню и сворачиваемые группы, контраст ≥ 4,5:1
(тест), минимальный шрифт 12, встроенные Noto Sans/Serif JP, тема «как в Windows», системная настройка анимаций,
скрытие маскота, рамка фокуса, документ [design-system.md](design-system.md). Не сделано: две колонки на широком экране (7.4.1),
главная с одной главной кнопкой (7.4.2), Mica (7.5.1), современные уведомления Windows (7.5.3), выбор шрифта и интервала в читалке (7.3.2).

## 5. Раздел 10

1. Игры: таймеры останавливаются при уходе со страницы (Unloaded) — проблем нет.
2. WritingPage, SpeechDetail — не проверялись подробно.
3. QuestsPage: засчитывается после всех сцен, повторное прохождение даёт меньше XP — проблем нет. PairsPage — XP за каждую попытку, без «пройдено».
4. Узкие экраны: `--cliptest` на минимальном окне без замечаний.
5. Audio: отказ в доступе к микрофону — сообщение и кнопка настроек конфиденциальности; отключение устройства — событие остановки с ошибкой.
6. Данные: 27 новых уроков проверены тестами формата; выборочную проверку старых переводов не делал.
7. Культура ru-RU: файлы и сеть идут через System.Text.Json и инвариантный разбор — проблем нет.
