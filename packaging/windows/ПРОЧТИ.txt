Kotodama — портативная версия

Запуск: Kotodama.exe. Ничего устанавливать не нужно (.NET встроен).
Требования: Windows 10 (1809+) или 11, 64-бит.

Переносить папку ЦЕЛИКОМ (exe, dll, runtimes, data, файл portable).
Все данные (прогресс, озвучка, модели) хранятся в папке data рядом с программой.

Уже внутри:
 - модель распознавания речи Whisper (проверка произношения работает офлайн);
 - кэш озвучки уже прослушанных фраз.

Нужен интернет: озвучка новых фраз онлайн-голосом (один раз, потом из кэша).
Полностью офлайн-голос: Настройки -> Офлайн-голоса VOICEVOX -> Установить.

Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» -> «Выполнить в любом случае».
Windows N/KN: для звука нужен бесплатный Media Feature Pack.
